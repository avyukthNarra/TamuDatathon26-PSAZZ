## 1. Problem Context, Constraints, and Baseline Diagnostics

### 1.1 Task & Evaluation Metric
- **Target:** For each query (one simulated slot machine at cutoff tick $T$), forecast the 5-category probability vector of the next payout at tick $T+1$: $P(0), P(1), P(2), P(5), P(20)$, where $0$ denotes a loss.
- **Scoring:** Squared error against the **true generating probabilities** $\mathbf{p}_{T+1}^*$ (not the sampled realization), computed as an error ratio $R$ vs. a fixed reference forecast, averaged equally over four conditions (`stable`, `short_history`, `drift`, `shared_change`), with total points $= 60 / (1 + R)$.
- **Generator Facts Found Empirically:**
  1. **Win/Loss ($y_t > 0$ vs. $y_t = 0$):** Depends on pairs of lagged binary outcomes up to lag 8 (on Round 1 train: $(1,3)$, $(2,5)$, and $(4,7)$). What matters is whether the two lagged outcomes **match or differ** (an XOR / parity / Walsh basis interaction). Machines of the same type can respond differently or *oppositely*. Round 2 changes which lag relationships recur.
  2. **Continuous Sigmoidal Win Distribution:** True win probabilities are U-shaped but continuous across population deciles (0.01, 0.02, 0.06, 0.13, 0.32, 0.66, 0.82, 0.91, 0.96), matching a logistic function of a weighted sum of signed lag terms rather than a two-level switch.
  3. **Payout Size Given Win ($y_t \in \{1, 2, 5, 20\}$):** Drawn from exactly one of two categorical mixes per machine type (`balanced`, `jackpot`, `steady`): "small mode" vs. "big mode". The active mode is switched by whether the spin 1, 2, 3, or 4 ticks back was a big win.
  4. **Shared Change:** In `shared_change` episodes (~8 machines per episode), machines share changepoint *times*, but not rules.
  5. **Runtime Constraints:** Offline CPU only (2 cores, 16 GB RAM, 30 minutes max runtime), deterministic Python (`numpy`/`scipy` allowed).

### 1.2 Current Baseline (55.34 / 60) and Error Breakdown
- **Architecture:** 20% Rule Model (searches lag rules per machine) + 80% Pair Mixer (online mixture of experts keeping exponentially forgotten win counts at half-lives 12 and 40 in "lags match / differ" cells, smoothed toward a two-component Beta-mixture prior at ~0.04 and ~0.90, weighted by $\exp(-\eta \cdot \text{recent Brier})$) + Bayes two-mode switch for payout size.

## 2. Research Questions & Methodological Specifications

### Section A: Learning a Sparse, Continuous Win Function per Machine from 64–250 Binary Observations

#### Question 1: Online/Sequential Bayesian Logistic Regression on Boolean (Walsh/Fourier) Features

##### Relevant Methods and Papers
1. **Jaakkola & Jordan (2000)** — *Bayesian parameter estimation via variational methods*, Statistics and Computing 10(1), 25–37 ([Semantic Scholar](https://www.semanticscholar.org/paper/Bayesian-parameter-estimation-via-variational-Jaakkola-Jordan/ee606afe92d1998d516f1e2599ddf8a386880d2a) | [Technical Derivation](https://tiao.io/posts/polya-gamma-sigmoid-local-variational-lower-bound/)).
2. **Polson, Scott, & Windle (2013)** — *Bayesian Inference for Logistic Models Using Polya-Gamma Latent Variables*, JASA 108(504), 1339–1349 ([arXiv:1205.0310](https://arxiv.org/abs/1205.0310)), paired with **Durante & Rigon (2019)** — *Conditionally Conjugate Mean-Field Variational Bayes for Logistic Models*, Statistical Science 34(3), 472–485 ([arXiv:1711.06999](https://arxiv.org/pdf/1711.06999) | [Project Euclid](https://projecteuclid.org/journals/statistical-science/volume-34/issue-3/Conditionally-Conjugate-Mean-Field-Variational-Bayes-for-Logistic-Models/10.1214/19-STS712.pdf)).
3. **MacKay (1992)** — *The Evidence Framework Applied to Classification Networks*, Neural Computation 4(5), 720–736 ([MIT Press PDF](https://direct.mit.edu/neco/article-pdf/4/5/720/812399/neco.1992.4.5.720.pdf)).
4. **Minka (2001)** — *Expectation Propagation for Approximate Bayesian Inference*, UAI 2001 ([Author PDF](https://tminka.github.io/papers/ep/minka-ep-uai.pdf) | [arXiv:1301.2294](https://arxiv.org/pdf/1301.2294)).

##### Methodological Explanation and Comparison
Let $s_{t-k} \in \{-1, +1\}$ denote the binary win/loss indicator at lag $k \in \{1, \dots, 8\}$ ($+1$ for win, $-1$ for loss), and let $\mathbf{x}_t \in \{-1, +1\}^P$ represent the Walsh basis vector containing an intercept $x_{t,0} = 1$, single lags $x_{t,k} = s_{t-k}$, and pairwise parity terms $x_{t,(j,k)} = s_{t-j} s_{t-k}$ ($+1$ when lags $j$ and $k$ match, $-1$ when they differ). Under a logistic link $P(y_t = 1 \mid \mathbf{x}_t, \boldsymbol{\beta}) = \sigma(\mathbf{x}_t^\top \boldsymbol{\beta}) = (1 + e^{-\mathbf{x}_t^\top \boldsymbol{\beta}})^{-1}$ with a Gaussian prior $\boldsymbol{\beta} \sim \mathcal{N}(\boldsymbol{\mu}_0, \boldsymbol{\Sigma}_0)$:

- **Sequential Laplace + MacKay Moderation (MacKay 1992; McCormick et al. 2012):** Approximates the posterior by $\mathcal{N}(\hat{\boldsymbol{\beta}}_t, \boldsymbol{\Sigma}_t)$ with precision update $\boldsymbol{\Sigma}_t^{-1} = \boldsymbol{\Sigma}_{t-1}^{-1} + p_t(1 - p_t)\mathbf{x}_t \mathbf{x}_t^\top$ where $p_t = \sigma(\mathbf{x}_t^\top \hat{\boldsymbol{\beta}}_{t-1})$. Instead of plugging $\hat{\boldsymbol{\beta}}_t$ directly into the sigmoid, MacKay integrates over the Gaussian posterior activation $a_t = \mathbf{x}_t^\top \boldsymbol{\beta} \sim \mathcal{N}(\mu_a, \sigma_a^2)$ (with $\mu_a = \mathbf{x}_t^\top \hat{\boldsymbol{\beta}}_t$ and $\sigma_a^2 = \mathbf{x}_t^\top \boldsymbol{\Sigma}_t \mathbf{x}_t$) via the probit-moderated sigmoid:
  $$P(y_{t+1} = 1 \mid \mathbf{x}_{t+1}, \mathcal{D}_{1:t}) \approx \sigma\!\left(\frac{\mu_a}{\sqrt{1 + \frac{\pi}{8}\sigma_a^2}}\right)$$
- **Jaakkola-Jordan Local Variational Bound / Variational Polya-Gamma (Jaakkola & Jordan 2000; Polson et al. 2013; Durante & Rigon 2019):** Lower-bounds the log-sigmoid around the local variational scale parameter $\xi_t = \sqrt{\mathbb{E}[(\mathbf{x}_t^\top \boldsymbol{\beta})^2]} = \sqrt{(\mathbf{x}_t^\top \boldsymbol{\mu})^2 + \mathbf{x}_t^\top \boldsymbol{\Sigma} \mathbf{x}_t}$:
  $$\log \sigma(\psi_t) \ge \frac{\psi_t - \xi_t}{2} - \log(1 + e^{-\xi_t}) - \lambda_{\text{JJ}}(\xi_t)(\psi_t^2 - \xi_t^2), \quad \lambda_{\text{JJ}}(\xi_t) = \frac{1}{4\xi_t}\tanh\!\left(\frac{\xi_t}{2}\right)$$
  Durante & Rigon (2019) proved that mean-field Variational Bayes on the Polya-Gamma augmented model ($q(\omega_t) = \text{PG}(1, \xi_t)$ with $\mathbb{E}[\omega_t] = \frac{1}{2\xi_t}\tanh(\xi_t/2) = 2\lambda_{\text{JJ}}(\xi_t)$) coincides **update-for-update** with Jaakkola-Jordan. Each tick updates the precision and information vector in closed form:
  $$\mathbf{P}_t = \mathbf{P}_{t-1} + \mathbb{E}[\omega_t]\mathbf{x}_t \mathbf{x}_t^\top, \qquad \mathbf{h}_t = \mathbf{h}_{t-1} + (y_t - 0.5)\mathbf{x}_t$$
- **Assumed-Density Filtering (ADF) / Expectation Propagation (Minka 2001):** Projects the exact tilted posterior onto a Gaussian by matching 1D cavity moments. Multi-pass EP can suffer from non-convergence unless damped.

| Method | Precision Weight per Tick | Small-Sample Calibration (N=64) | CPU Runtime (600 Machines, T=250) | Implementation Verdict |
| :--- | :--- | :--- | :--- | :--- |
| Sequential Laplace + MacKay Moderation | p_t(1 - p_t) at MAP mode | Can underestimate variance if MAP mode is large | ~0.4 sec total | Fast; use MacKay moderation |
| Jaakkola-Jordan / Variational Polya-Gamma | E[w_t] = tanh(xi_t/2)/(2*xi_t) | Best: xi_t includes posterior variance sigma_a^2 | ~0.5 sec (1-pass) to ~1.8 sec (CAVI) | Recommended primary engine |
| Assumed-Density Filtering (ADF) / EP | Moment-matched log-Z derivative | High marginal accuracy; EP can oscillate | ~0.8 sec (ADF) to ~4.5 sec (EP) | Secondary alternative |
| Stochastic Polya-Gamma Gibbs MCMC | Sampled PG(1, abs(x_t' beta)) | Monte Carlo variance hurts Brier score | ~45-90 sec total | Avoid (use Variational PG instead) |

##### Concrete Integration into Current Architecture
Add a **Variational Polya-Gamma (Jaakkola-Jordan) Logistic Expert** alongside the Pair Mixer (60% PG-Logistic BMA + 40% Pair Mixer). Maintain exponentially discounted sufficient statistics at half-lives $h \in \{4, 12, 40, \infty\}$ with $\gamma = 2^{-1/h}$:
$$\mathbf{P}_t = \boldsymbol{\Sigma}_0^{-1} + \sum_{\tau=1}^t \gamma^{t-\tau} \mathbb{E}[\omega_\tau] \mathbf{x}_\tau \mathbf{x}_\tau^\top, \qquad \mathbf{h}_t = \boldsymbol{\Sigma}_0^{-1}\boldsymbol{\mu}_0 + \sum_{\tau=1}^t \gamma^{t-\tau}(y_\tau - 0.5)\mathbf{x}_\tau$$
At query cutoff $T$, compute $\boldsymbol{\Sigma}_T = \mathbf{P}_T^{-1}$ and $\boldsymbol{\mu}_T = \boldsymbol{\Sigma}_T \mathbf{h}_T$ (using 2 fast CAVI iterations on the top-screened active features) and output the MacKay probit-moderated win probability.

##### Expected Difficulty and Risks
- **Difficulty:** ~2.0 hours.
- **Risks:** Fitting all $P = 37$ features simultaneously on $N = 64$ observations underestimates posterior variance and overfits noise parities. Restrict the PG-Logistic filter to top-screened features (Question 2) and average across low-degree subsets of size $\le 3$ via BMA (Question 4).

#### Question 2: Learning Sparse Parities and Low-Degree Boolean Functions with Noise

##### Relevant Methods and Papers
1. **O'Donnell (2014 / 2021)** — *Analysis of Boolean Functions*, Cambridge University Press ([arXiv:2105.10386](https://arxiv.org/abs/2105.10386) | [CMU Full Text PDF](https://www.cs.cmu.edu/~odonnell/papers/Analysis-of-Boolean-Functions-by-Ryan-ODonnell.pdf)), and **Linial, Mansour, & Nisan (1993)** — *Constant depth circuits, Fourier transform, and learnability*, JACM 40(3), 607–620 ([KTH PDF](https://www.csc.kth.se/~johanh/lmnsharp.pdf)).
2. **Mossel, O'Donnell, & Servedio (2003 / 2004)** — *Learning Juntas*, STOC 2003 / JCSS 69(3), 421–434 ([CMU PDF](https://www.cs.cmu.edu/~odonnell/papers/juntas.pdf) | [Noisy Juntas Extension](https://scispace.com/pdf/learning-juntas-in-the-presence-of-noise-1e5vajguzo.pdf)).
3. **Vuffray, Misra, Lokhov, & Chertkov (2016 / 2020)** — *Interaction Screening: Efficient and Sample-Optimal Learning of Ising Models*, NeurIPS 2016 ([arXiv:1605.07252](https://arxiv.org/abs/1605.07252)) and *Efficient Learning of Discrete Graphical Models (GRISE)*, NeurIPS 2020 ([NeurIPS PDF](https://proceedings.neurips.cc/paper/2020/file/9d702ffd99ad9c70ac37e506facc8c38-Paper.pdf)), alongside **Bresler (2015)** — *Efficiently Learning Ising Models on Arbitrary Graphs*, STOC 2015 ([arXiv:1411.6156](https://arxiv.org/abs/1411.6156)).
4. **Jain, Tewari, & Kar (2014)** — *On Iterative Hard Thresholding Methods for High-dimensional M-Estimation*, NeurIPS 2014 ([arXiv:1410.5137](https://arxiv.org/abs/1410.5137) | [Author PDF](https://www.ambujtewari.com/research/jain14iterative.pdf)).

##### Methodological Explanation and Sample Complexity Analysis
With $n = 8$ lags, there are $\binom{8}{1} = 8$ degree-1 terms and $\binom{8}{2} = 28$ degree-2 parity terms ($P = 36$ total candidate Boolean basis functions). By Hoeffding's inequality and a union bound over $P = 36$ terms, estimating all empirical Walsh-Fourier coefficients $\tilde{f}_S(I) = \frac{1}{m}\sum_{t=1}^m \tilde{y}_t \chi_I(\mathbf{s}_t)$ within additive error $\varepsilon$ with probability $1 - \delta$ requires:
$$m \ge \frac{2}{\varepsilon^2} \ln\!\left(\frac{2P}{\delta}\right) = \frac{2}{\varepsilon^2} \ln\!\left(\frac{72}{\delta}\right)$$
For $\delta = 0.05$, $\ln(72/0.05) = 7.27$. At $m = 64$, per-coordinate standard error is $1/\sqrt{64} = 0.125$ (worst-case uniform bound $\varepsilon \approx 0.47$); at $m = 200$, per-coordinate error is $0.071$ ($\varepsilon \approx 0.27$). Active terms with $|\beta_S| \ge 1.2$ induce marginal correlations $\approx 0.58$, exceeding the $2.5\sigma$ coordinate noise threshold.

**Why the previously tried signed-$L_1$ interaction logistic (~48 points) failed:**
1. **Amplitude Shrinkage Bias:** Suppressing 33 noise features at $m = 64$ requires a large $L_1$ penalty $\lambda \propto \sqrt{\ln(P)/m}$, which soft-thresholds the true active logits $|\beta_S|$ toward zero, collapsing the U-shaped probability distribution (0.01–0.96) toward 0.25–0.75.
2. **Collinearity under Biased Win Rates ($p \neq 0.5$):** When a machine's base win rate is far from $0.5$, raw uncentered parity terms $s_{t-j}s_{t-k}$ become strongly correlated with single lags and with each other.

**Solutions:**
1. **$p$-Biased Fourier Basis Orthogonalization (O'Donnell 2014):** Standardize each observed lag by the machine's running mean $\hat{\mu}_t = \mathbb{E}[s_t]$: $\tilde{s}_{t-k} = (s_{t-k} - \hat{\mu}_t)/\sqrt{1 - \hat{\mu}_t^2}$ (and $\tilde{s}_{t-k} = 0$ if missing in a gap), then define degree-2 terms $\phi_{(j,k)}(t) = \tilde{s}_{t-j}\tilde{s}_{t-k}$.
2. **Iterative Hard Thresholding / OMPR (Jain, Tewari, & Kar 2014) + Debiased Conjugate Refit:** Project onto the $L_0$ ball of size $s \le 3$ and refit with unpenalized/Gaussian-slab Bayesian logistic regression on the selected support to eliminate $L_1$ bias.

##### Concrete Integration into Current Architecture
Replace the brute-force rule search in the 20% Rule Model (and feed the PG-Logistic BMA expert) with a **Centered $p$-Biased Walsh Screener** that ranks the 36 features by their variance-normalized inner product $|z_r| = |\sum_\tau w_\tau (y_\tau - \bar{y}) \phi_r(\tau)| / \sqrt{\sum_\tau w_\tau \phi_r(\tau)^2 + 4}$ and passes the top $K = 6$ features into the exact subset BMA engine.

##### Expected Difficulty and Risks
- **Difficulty:** 2.0 to 2.5 hours.
- **Risks:** In `short_history` ($m = 64$ with 20 gaps), hard-selecting a single support of size $s = 3$ can include a false-positive noise pair; always average across the top subsets via BMA (Question 4).

#### Question 3: Hierarchical Priors with Shared Effect Magnitude and Machine-Specific Sign

##### Relevant Methods and Papers
1. **Johnson & Rossell (2010)** — *On the use of non-local prior densities in Bayesian hypothesis tests*, JRSS-B 72(2), 143–170 ([ResearchGate](https://www.researchgate.net/publication/46537471_On_the_use_of_non-local_prior_densities_in_Bayesian_hypotesis_tests) | [MOM Extension arXiv:2603.08285](https://arxiv.org/pdf/2603.08285)).
2. **Piironen & Vehtari (2017)** — *Sparsity information and regularization in the horseshoe and other shrinkage priors*, Electronic Journal of Statistics 11(2), 5018–5051 ([arXiv:1707.01694](https://arxiv.org/abs/1707.01694) | [Project Euclid PDF](https://projecteuclid.org/journals/electronic-journal-of-statistics/volume-11/issue-2/Sparsity-information-and-regularization-in-the-horseshoe-and-other-shrinkage/10.1214/17-EJS1337SI.pdf)), building on **Carvalho, Polson, & Scott (2010)** ([Semantic Scholar](https://www.semanticscholar.org/paper/The-horseshoe-estimator-for-sparse-signals-Carvalho-Polson/51d88925443329a35e9afe25a4b9cdbc4fd8e04d)).
3. **Rockova & George (2014)** — *EMVS: The EM Approach to Bayesian Variable Selection*, JASA 109(506), 828–846 ([ResearchGate](https://www.researchgate.net/publication/263288233_EMVS_The_EM_Approach_to_Bayesian_Variable_Selection)) and **Rockova & George (2018)** — *The Spike-and-Slab LASSO*, JASA 113(521), 431–444 ([arXiv:2010.06451](https://arxiv.org/pdf/2010.06451)).
4. **Gelman, Jakulin, Pittau, & Su (2008)** — *A weakly informative default prior distribution for logistic and other regression models*, Annals of Applied Statistics 2(4), 1360–1383 ([arXiv:0901.4011](https://arxiv.org/abs/0901.4011) | [Columbia PDF](https://sites.stat.columbia.edu/gelman/research/published/priors11.pdf)).

##### Methodological Explanation
Previously tried type-level cell shrinkage and train-learned pair priors failed because (1) machines of the same type respond *oppositely* (shrinking $+1.8$ and $-1.8$ toward a shared mean cancels the signal to $0$), and (2) Round 2 changes which lag pairs are active. To share statistical strength across a machine type (`balanced`, `jackpot`, `steady`) while remaining 100% invariant to sign flips and Round-2 lag permutations:
- **Symmetric Sign-Flip Mixture / Non-Local MOM Prior (Johnson & Rossell 2010):**
  $$p(\beta_{m,r} \mid \gamma_{m,r} = 1, b_{g(m)}, \sigma_{g(m)}^2) = \frac{1}{2}\mathcal{N}(\beta_{m,r}; +b_{g(m)}, \sigma_{g(m)}^2) + \frac{1}{2}\mathcal{N}(\beta_{m,r}; -b_{g(m)}, \sigma_{g(m)}^2)$$
- **Regularized ("Finnish") Horseshoe Slab Scale (Piironen & Vehtari 2017):** Regularizes active coefficients via a finite Gaussian slab $\mathcal{N}(0, c_{g(m)}^2)$ shared across machine type $g(m)$:
  $$\beta_{m,r} \mid \tilde{\lambda}_{m,r}, \tau_{g(m)}, c_{g(m)} \sim \mathcal{N}\!\left(0, \tau_{g(m)}^2 \tilde{\lambda}_{m,r}^2\right), \qquad \tilde{\lambda}_{m,r}^2 = \frac{c_{g(m)}^2 \lambda_{m,r}^2}{c_{g(m)}^2 + \tau_{g(m)}^2 \lambda_{m,r}^2}$$

##### Concrete Integration into Current Architecture
Estimate the unsigned active slab variance $c_{\text{type}}^2 = \text{mean}(\hat{\beta}_{m,r_{\text{active}}}^2)$ and intercept variance $c_{0,\text{type}}^2$ per `machine_type` across long-history machines on the active dataset, and set the BMA slab prior covariance to $\boldsymbol{\Sigma}_0 = \text{diag}(c_{0,\text{type}}^2, c_{\text{type}}^2, \dots, c_{\text{type}}^2)$.

##### Expected Difficulty and Risks
- **Difficulty:** ~2.0 hours.
- **Risks:** Enforcing a hard nonzero prior mean $\pm b_{\text{type}}$ before 20 ticks can lock in the wrong sign; use the zero-mean Gaussian slab $\mathcal{N}(0, c_{\text{type}}^2)$ for exact BMA marginal likelihoods.

#### Question 4: Fast Bayesian Model Averaging Over Active Lag Terms vs. Context-Tree Weighting

##### Relevant Methods and Papers
1. **Madigan & Raftery (1994)** — *Model Selection and Accounting for Model Uncertainty in Graphical Models Using Occam's Window*, JASA 89(428), 1535–1546 ([Semantic Scholar](https://www.semanticscholar.org/paper/Model-Selection-and-Accounting-for-Model-in-Models-Madigan-Raftery/cbb7afa526e1f947520ffeec8f734794802ee3c7)), and **Clyde, Ghosh, & Littman (2011)** — *Bayesian Adaptive Sampling for Variable Selection and Model Averaging (BAS)*, JCGS 20(1), 80–101 ([Duke PDF](http://www2.stat.duke.edu/~clyde/BAS/BAS-paper.pdf)).
2. **Willems, Shtarkov, & Tjalkens (1995)** — *The Context-Tree Weighting Method: Basic Properties*, IEEE Trans. Information Theory 41(3), 653–664 ([CMU PDF](https://www.cs.cmu.edu/~aarti/Class/10704_Fall16/CTW.pdf)), using **Krichevsky & Trofimov (1981)** ([Semantic Scholar](https://www.semanticscholar.org/paper/The-performance-of-universal-encoding-Krichevsky-Trofimov/ffce7d33e742a0dd1bd2a3cf6613674f1e7002df)).
3. **Veness, Ng, Hutter, Uther, & Silver (2012) / Bellemare et al. (2014)** — *Context Tree Switching (CTS)* ([Author PDF](http://www.hutter1.net/publ/ctswitch.pdf)) and *Skip Context Tree Switching (SkipCTS)*, ICML 2014 ([PMLR PDF](http://proceedings.mlr.press/v32/bellemare14.pdf)).
4. **Begleiter, El-Yaniv, & Yona (2004)** — *On Prediction Using Variable Order Markov Models*, JAIR 22, 385–421 ([arXiv:1107.0051](https://arxiv.org/abs/1107.0051)), and **Dimitrakakis (2010)** — *Bayesian Variable Order Markov Models*, AISTATS 2010 ([PMLR PDF](http://proceedings.mlr.press/v9/dimitrakakis10a/dimitrakakis10a.pdf)).

##### Methodological Explanation
- **Screened Conjugate Gaussian BMA with Occam's Window:** Once the $(K+1)\times(K+1)$ Polya-Gamma precision matrix $\mathbf{P}_T$ and vector $\mathbf{h}_T$ are accumulated on the top $K = 6$ screened Walsh features, every subset $\gamma \subseteq \{1, \dots, K\}$ of size $|\gamma| \le 3$ (only $\sum_{j=0}^3 \binom{6}{j} = 42$ subsets) shares sub-blocks $\mathbf{P}_{T,\gamma}$ and $\mathbf{h}_{T,\gamma}$. The closed-form Gaussian log-marginal likelihood with multiplicity prior penalty $\binom{36}{|\gamma|}^{-1}$ is:
  $$\log P(\mathcal{D}_{1:T} \mid \mathcal{M}_\gamma) = -\frac{|\gamma|}{2}\log(c_{\text{type}}^2) - \frac{1}{2}\log \det(\mathbf{P}_{T,\gamma}) + \frac{1}{2}\mathbf{h}_{T,\gamma}^\top \mathbf{P}_{T,\gamma}^{-1} \mathbf{h}_{T,\gamma} - \log\binom{36}{|\gamma|}$$
- **Why Standard CTW/VMM Struggles on Raw Lags:** Chronological context trees branch in fixed order ($t-1, t-2, \dots, t-7$), requiring depth 7 ($2^7 = 128$ leaves) to reach lag pair $(4,7)$ and failing to enforce additive log-odds across levels.

##### Concrete Integration into Current Architecture
Evaluate the closed-form log-evidence across all 42 subsets $\gamma$ of the top $K = 6$ Walsh features, prune subsets outside Madigan & Raftery's Occam's Window ($\Delta \log P < -3.0$), and compute posterior model weights $w_\gamma = \text{softmax}_\gamma(\log P(\mathcal{D}_{1:T} \mid \mathcal{M}_\gamma))$.

##### Expected Difficulty and Risks
- **Difficulty:** ~1.5 hours.
- **Risks:** Winner's curse from screening $K = 6$ out of 36 features; mitigated by the $\log\binom{36}{|\gamma|}$ multiplicity penalty.

#### Question 5: Comparison of Sparse Logistic BMA vs. Count-Based Cell Estimates + Beta-Mixture Smoothing

##### Relevant Methods and Papers
1. **McCormick, Raftery, Madigan, & Burd (2012)** — *Dynamic Logistic Regression and Dynamic Model Averaging for Binary Classification*, Biometrics 68(1), 23–30 ([Oxford Biometrics](https://academic.oup.com/biometrics/article/68/1/23/7390679)).
2. **O'Donnell (2014)** — *Analysis of Boolean Functions*, Cambridge University Press ([arXiv:2105.10386](https://arxiv.org/abs/2105.10386)).
3. **Gneiting & Raftery (2007)** — *Strictly Proper Scoring Rules, Prediction, and Estimation*, JASA 102(477), 359–378 ([UW Stat PDF](https://sites.stat.washington.edu/raftery/Research/PDF/Gneiting2007jasa.pdf)).

##### Quantitative Diagnosis of the Pair Mixer's Convexity Trap
Suppose a machine has true generating logit $\eta(\mathbf{x}) = 1.4 \chi_{p_1} + 1.1 \chi_{p_2} + 0.7 \chi_{p_3}$ over 3 active pairs. Across the $2^3 = 8$ parity configurations, the true probabilities are $\{0.039, 0.142, 0.269, 0.401, 0.599, 0.731, 0.858, 0.961\}$.
- In the **Pair Mixer**, Expert 1 only conditions on $\chi_{p_1} = +1$, averaging over the 4 states of $(\chi_{p_2}, \chi_{p_3})$ to converge to $p_1(+1) = \frac{1}{4}(0.401 + 0.731 + 0.858 + 0.961) = 0.738$. Similarly, Expert 2 converges to $p_2(+1) = 0.705$, and Expert 3 to $p_3(+1) = 0.640$.
- When all three pairs align ($\chi_{p_1} = \chi_{p_2} = \chi_{p_3} = +1$), the **true probability is 0.961**, but any convex linear combination $\sum_k w_k p_k(+1)$ is bounded above by $\max_k p_k(+1) = 0.738$ (predicting ~0.712).
- The Pair Mixer's bimodal Beta prior (0.04 and 0.90) partially pulls small-sample cell means toward the extremes, but distorts intermediate deciles (0.13, 0.32, 0.66).
- **Screened PG-Logistic BMA** sums the log-odds $\sum_k \beta_k \chi_{p_k}$ directly, recovering 0.961 when all 3 pairs align, 0.401–0.731 when pairs partially cancel, and analytically inflating variance $\sigma_a^2$ in MacKay's denominator when a lag is missing in `short_history`.

### Section B: Non-Stationarity (Drift and Shared Changepoints)

##### Relevant Methods and Papers
1. **McCormick, Raftery, Madigan, & Burd (2012)** — *Dynamic Logistic Regression and Dynamic Model Averaging for Binary Classification*, Biometrics 68(1), 23–30 ([Oxford Biometrics](https://academic.oup.com/biometrics/article/68/1/23/7390679)), extending **Raftery, Karny, & Ettler (2010)** ([ResearchGate](https://www.researchgate.net/publication/45098048_Online_Prediction_Under_Model_Uncertainty_via_Dynamic_Model_Averaging_Application_to_a_Cold_Rolling_Mill)).

#### Question 7: Hierarchical / Multi-Series Bayesian Online Changepoint Detection with Shared Times and Independent Parameters

##### Relevant Methods and Papers
1. **Adams & MacKay (2007)** — *Bayesian Online Changepoint Detection (BOCPD)*, arXiv:0710.3742 ([arXiv:0710.3742](https://arxiv.org/abs/0710.3742)).
2. **Xuan & Murphy (2007)** — *Modeling Changing Dependency Structure in Multivariate Time Series*, ICML 2007, 1055–1062 ([UBC Author PDF](https://www.cs.ubc.ca/~murphyk/Papers/xuanICML07.pdf)).
3. **Fearnhead & Liu (2007)** — *On-line inference for multiple changepoint problems*, JRSS-B 69(4), 589–605 ([ResearchGate](https://www.researchgate.net/publication/4772372_On-line_inference_for_multiple_changepoint_problems)), and **Bardwell & Fearnhead (2017)** — *Bayesian Detection of Abnormal Segments in Multiple Time Series*, Bayesian Analysis 12(1), 193–218 ([Lancaster Portal](https://research.lancaster-university.uk/en/publications/efficient-search-methods-for-high-dimensional-time-series/publications/)).

##### Methodological Explanation
Univariate BOCPD fails on a single binary series because overcoming a changepoint hazard prior $H \approx 0.02$ ($\log((1-H)/H) \approx 3.9$ nats) takes 15–25 ticks of Bernoulli observations. Under the **Xuan & Murphy (2007) Independent Features Model (IFM)** combined with **Adams & MacKay (2007)**, the run-length state $r_t$ is shared across all $M \approx 8$ machines in the episode while emission parameters $\boldsymbol{\theta}_m^{(r_t)}$ remain strictly independent across machines:
$$P\left(\mathbf{y}_{1:M, t} \mid r_{t-1} = r, \mathcal{D}_{1:t-1}\right) = \prod_{m=1}^M P_m\left(y_{m,t} \mid r_{t-1} = r, \mathcal{D}_{m, t-r:t-1}\right)$$
Summing log-likelihood ratios across all 8 peers multiplies the changepoint surprise signal by $8\times$, crossing the hazard threshold within **2–3 ticks**. Running both the coupled episode filter ($\mathcal{L}_{1:T}^{\text{sync}}$) and independent machine filters ($\mathcal{L}_{1:T}^{\text{ind}}$) in parallel yields an automatic Bayesian gate $w_{\text{sync}}(T) = \sigma(\mathcal{L}_{1:T}^{\text{sync}} - \mathcal{L}_{1:T}^{\text{ind}} + \log(p_0/(1-p_0)))$ that activates peer coupling only in `shared_change` episodes.

##### Concrete Integration into Current Architecture
See **Rank 2 Experiment** in Section 3 below for exact 4-horizon Markov transition matrices and vectorized NumPy equations.

##### Expected Difficulty and Risks
- **Difficulty:** ~2.0 hours.
- **Risks:** A single machine outlier prediction could trigger a false episode reset; clip per-machine log-likelihood ratios to $[-1.2, +1.2]$ before summing across the 8 peers.

##### Relevant Methods and Papers
1. **Gneiting & Raftery (2007)** — *Strictly Proper Scoring Rules, Prediction, and Estimation*, JASA 102(477), 359–378 ([UW Stat PDF](https://sites.stat.washington.edu/raftery/Research/PDF/Gneiting2007jasa.pdf)).

3. **Lokhov, Vuffray, Misra, & Chertkov (2018) / Dutt, Lokhov, Vuffray, & Misra (2021)** — *Optimal structure and parameter learning of Ising models*, Science Advances 4(3) ([ResearchGate](https://www.researchgate.net/publication/311668856_Optimal_structure_and_parameter_learning_of_Ising_models)), and *Exponential Reduction in Sample Complexity with Learning of Ising Model Dynamics*, ICML 2021 ([Author Portal](http://www.lptms.universite-paris-saclay.fr/andrey-lokhov/research/)).

##### Scoring-Rule Decomposition and Concrete Takeaway
For true generating probabilities $\mathbf{p}_t^*$ and sampled one-hot outcome $\mathbf{y}_t$:
$$\mathbb{E}_{\mathbf{y}_t \sim \mathbf{p}_t^*}\!\left[\|\hat{\mathbf{p}}_t - \mathbf{y}_t\|_2^2\right] = \sum_{c=1}^5 p_{t,c}^*(1 - p_{t,c}^*) + \|\hat{\mathbf{p}}_t - \mathbf{p}_t^*\|_2^2$$
1. **Why Temperature Scaling & Log-Pools Failed:** Under squared error against $\mathbf{p}_t^*$, the unique Bayes-optimal forecast is the **posterior mean** $\hat{\mathbf{p}}_t = \mathbb{E}[\mathbf{p}_t^* \mid \mathcal{D}] = \sum_k w_k \hat{\mathbf{p}}_k$ (a linear pool over posterior model probabilities).
2. **Why $\exp(-\eta \cdot \text{Brier})$ Expert Weights Are Suboptimal Online:** Sampled Brier differences contain high-variance martingale noise $-2(\hat{\mathbf{p}}_A - \hat{\mathbf{p}}_B)^\top(\mathbf{y}_t - \mathbf{p}_t^*)$. By Gneiting & Raftery (2007, Section 7.1), posterior model weights $w_k$ must be updated online using **clipped Logarithmic Score (log-likelihood Bayes factors)**, while predictions are combined **linearly**.

### Experiment 1 (Rank 1): Screened Conjugate Walsh-Logistic BMA with Gap-Variance Moderation
- **Target:** Win probability (+3.02 pt oracle ceiling; specifically attacks `short_history` 0.121 and `stable` 0.063).
- **Estimated Effort:** 2.5 hours | **Runtime:** ~1.5 seconds for 600 machines | **Expected Gain:** +1.1 to +1.5 dev points.

#### Step-by-Step Mathematical & Code Specification
1. **Standardized $p$-Biased Walsh Feature Extraction (Handles Missing Lags):**
   - Given spin sequence $y_{1:T}$ (with `NaN` or `-1` at missing gap ticks), define observed indicator $o_t = \mathbb{I}(y_t \text{ is observed})$ and binary win spin $s_t = +1$ if $y_t > 0$ else $-1$ when $o_t = 1$.
   - Track running exponentially weighted mean $\bar{s}_t$ (clipped to $[-0.85, +0.85]$) and standard deviation $\sigma_{s,t} = \sqrt{1 - \bar{s}_t^2}$.
   - For each lag $k \in \{1, \dots, 8\}$ at tick $t$:
     $$\tilde{s}_{t-k} = \begin{cases} \frac{s_{t-k} - \bar{s}_t}{\sigma_{s,t}} & \text{if tick } t-k \text{ is observed} \\ 0.0 & \text{if tick } t-k \text{ is missing (in a gap) or } t - k < 1 \end{cases}$$
   - Construct the $P = 36$ Walsh candidate vector $\boldsymbol{\phi}(t) \in \mathbb{R}^{36}$:
     - Indices $0 \dots 7$: single lags $\phi_k(t) = \tilde{s}_{t-k}$ for $k \in \{1, \dots, 8\}$.
     - Indices $8 \dots 35$: pairwise parities $\phi_{(j,k)}(t) = \tilde{s}_{t-j}\tilde{s}_{t-k}$ for $1 \le j < k \le 8$.

2. **Fast Marginal Screening per Horizon $h \in \{4, 12, 40, \infty\}$:**
   - For forgetting factor $\gamma_h = 2^{-1/h}$ (with $\gamma_\infty = 1.0$), compute discounted weights $w_\tau = \gamma_h^{T-\tau} o_\tau$ for $\tau = 1, \dots, T$.
   - Let $\bar{y}_h = \frac{\sum_\tau w_\tau y_\tau}{\sum_\tau w_\tau + 10^{-8}}$ where $y_\tau \in \{0, 1\}$.
   - Compute marginal score for each feature $r \in \{0, \dots, 35\}$:
     $$z_r = \frac{\left|\sum_{\tau=1}^T w_\tau (y_\tau - \bar{y}_h)\phi_r(\tau)\right|}{\sqrt{\sum_{\tau=1}^T w_\tau \phi_r(\tau)^2 + 4.0}}$$
   - Select the top $K = 6$ feature indices $\mathcal{I}_h = \text{argsort}(-z)[:6]$. Form design matrix $\mathbf{X}_h \in \mathbb{R}^{T \times 7}$ with column 0 as $1.0$ (intercept) and columns $1 \dots 6$ as $\boldsymbol{\phi}_{\mathcal{I}_h}(\tau)$.

3. **2-Pass Coordinate Ascent Variational Polya-Gamma (Jaakkola-Jordan) Sufficient Statistics:**
   - Set diagonal prior precision $\mathbf{P}_0 = \text{diag}(c_{0,\text{type}}^{-2}, c_{\text{type}}^{-2}, \dots, c_{\text{type}}^{-2}) \in \mathbb{R}^{7 \times 7}$ (default $c_{0,\text{type}} = 2.0$, $c_{\text{type}} = 1.35$, tuned on validation per `machine_type`).
   - Initialize $\omega_\tau = 0.25 w_\tau$. Run 2 iterations:
     - $\mathbf{P}_T = \mathbf{P}_0 + \mathbf{X}_h^\top \text{diag}(\boldsymbol{\omega}) \mathbf{X}_h$
     - $\mathbf{h}_T = \mathbf{X}_h^\top \left(w \odot (y - 0.5)\right)$
     - $\boldsymbol{\Sigma}_T = \mathbf{P}_T^{-1}, \quad \boldsymbol{\mu}_T = \boldsymbol{\Sigma}_T \mathbf{h}_T$
     - $\xi_\tau = \sqrt{(\mathbf{x}_\tau^\top \boldsymbol{\mu}_T)^2 + \mathbf{x}_\tau^\top \boldsymbol{\Sigma}_T \mathbf{x}_\tau}, \quad \omega_\tau = w_\tau \frac{\tanh(\xi_\tau / 2)}{2 \max(\xi_\tau, 10^{-6})}$

4. **Exact Sub-Model BMA over the 42 Subsets of Size $|\gamma| \le 3$ + Gap-Variance Moderation:**
   - Enumerate all 42 subsets $\gamma \subseteq \{1, \dots, 6\}$ with $|\gamma| \le 3$; let $I_\gamma = [0] + \gamma$ always include the intercept (index 0).
   - Extract sub-matrix $\mathbf{P}_\gamma = \mathbf{P}_T[I_\gamma, I_\gamma]$ and sub-vector $\mathbf{h}_\gamma = \mathbf{h}_T[I_\gamma]$.
   - Solve $\hat{\boldsymbol{\beta}}_\gamma = \mathbf{P}_\gamma^{-1} \mathbf{h}_\gamma$ and $\boldsymbol{\Sigma}_\gamma = \mathbf{P}_\gamma^{-1}$.
   - Compute log-marginal likelihood:
     $$\log M_\gamma = -\frac{1}{2}\log\det(\mathbf{P}_\gamma) + \frac{1}{2}\mathbf{h}_\gamma^\top \hat{\boldsymbol{\beta}}_\gamma - \frac{|\gamma|}{2}\log(c_{\text{type}}^2) - \log\binom{36}{|\gamma|}$$
   - Apply Occam's Window: mask out any $\gamma$ with $\log M_\gamma < \max_{\gamma'} \log M_{\gamma'} - 3.0$, then set $w_\gamma = \text{softmax}(\log M_\gamma)$.
   - **Query Prediction at $T+1$ with Analytical Missing-Lag Moderation:**
     - Construct $\mathbf{x}_{T+1, \gamma}$. For any active feature $r \in \gamma$ whose underlying lag(s) at $T+1$ are unobserved (missing in a gap), $x_{T+1, r} = 0$.
     - Compute mean activation $\mu_{a,\gamma} = \mathbf{x}_{T+1,\gamma}^\top \hat{\boldsymbol{\beta}}_\gamma$.
     - Compute total activation variance including missing-feature uncertainty:
       $$\sigma_{a,\gamma}^2 = \mathbf{x}_{T+1,\gamma}^\top \boldsymbol{\Sigma}_\gamma \mathbf{x}_{T+1,\gamma} + \sum_{r \in \gamma : \text{missing at } T+1} \left(\hat{\beta}_{\gamma, r}^2 + \Sigma_{\gamma, rr}\right)$$
     - Compute moderated probability $\hat{p}_\gamma = \sigma\!\left(\frac{\mu_{a,\gamma}}{\sqrt{1 + \frac{\pi}{8}\sigma_{a,\gamma}^2}}\right)$ and BMA output $\hat{p}_{m,T+1}^{(h)} = \sum_\gamma w_\gamma \hat{p}_\gamma$.
   - **Denoised Pair Mixer Weighting:** Inside the existing Pair Mixer, replace $\exp(-\eta \cdot \text{Brier})$ expert weights with clipped log-likelihood weights $\sum_\tau \gamma_h^{T-\tau} \log(\text{clip}(\hat{p}_{e,\tau}, 0.005, 0.995)^{y_\tau}(1 - \text{clip}(\hat{p}_{e,\tau}, 0.005, 0.995))^{1-y_\tau})$, and blend 60% Walsh-Logistic BMA + 40% Pair Mixer.

```python
import numpy as np
from itertools import combinations
from math import comb

# Precompute the 42 subset index lists (always including intercept index 0) for K=6
SUBSETS_K6 = [[0] + list(c) for d in range(4) for c in combinations(range(1, 7), d)]
MULT_PENALTY_K6 = np.array([np.log(comb(36, len(s) - 1)) for s in SUBSETS_K6])

def walsh_bma_predict_horizon(X_hist, y_hist, obs_mask, x_next, next_missing_mask,
                              gamma, c0=2.0, c_slab=1.35):
    """
    X_hist: (T, 36) standardized Walsh features on history
    y_hist: (T,) binary win indicator in {0.0, 1.0}
    obs_mask: (T,) boolean/float mask (1.0 if tick t observed, 0.0 if gap)
    x_next: (36,) standardized Walsh features for query tick T+1 (0.0 where missing)
    next_missing_mask: (36,) boolean mask (True if feature r at T+1 depends on a missing lag)
    """
    T = len(y_hist)
    ticks_ago = np.arange(T - 1, -1, -1, dtype=np.float64)
    w = (gamma ** ticks_ago) * obs_mask
    w_sum = np.sum(w)
    if w_sum < 1e-6:
        return 0.5

    y_bar = np.sum(w * y_hist) / w_sum
    centered_y = w * (y_hist - y_bar)
    # Screen top K=6 Walsh features
    num = np.abs(X_hist.T @ centered_y)
    den = np.sqrt((X_hist ** 2).T @ w + 4.0)
    top_idx = np.argsort(-(num / den))[:6]

    X_sub = np.column_stack([np.ones(T), X_hist[:, top_idx]])  # (T, 7)
    P0_diag = np.array([1.0 / (c0 ** 2)] + [1.0 / (c_slab ** 2)] * 6)
    h_vec = X_sub.T @ (w * (y_hist - 0.5))

    # 2-pass Variational Polya-Gamma (Jaakkola-Jordan)
    omega = 0.25 * w
    for _ in range(2):
        P_mat = np.diag(P0_diag) + (X_sub.T * omega) @ X_sub
        Sigma = np.linalg.inv(P_mat)
        mu = Sigma @ h_vec
        proj_mean = X_sub @ mu
        proj_var = np.sum((X_sub @ Sigma) * X_sub, axis=1)
        xi = np.maximum(np.sqrt(np.maximum(proj_mean ** 2 + proj_var, 0.0)), 1e-6)
        omega = w * (np.tanh(0.5 * xi) / (2.0 * xi))

    P_mat = np.diag(P0_diag) + (X_sub.T * omega) @ X_sub
    x_q_full = np.concatenate([[1.0], x_next[top_idx]])
    miss_q_full = np.concatenate([[False], next_missing_mask[top_idx]])

    log_evidences = np.empty(len(SUBSETS_K6))
    preds = np.empty(len(SUBSETS_K6))
    log_c2 = np.log(c_slab ** 2)

    for idx, s in enumerate(SUBSETS_K6):
        P_s = P_mat[np.ix_(s, s)]
        h_s = h_vec[s]
        Sigma_s = np.linalg.inv(P_s)
        beta_s = Sigma_s @ h_s
        sign, logdet = np.linalg.slogdet(P_s)
        d = len(s) - 1
        log_evidences[idx] = (
            -0.5 * logdet + 0.5 * (h_s @ beta_s)
            - 0.5 * d * log_c2 - MULT_PENALTY_K6[idx]
        )
        x_q = x_q_full[s]
        miss_q = miss_q_full[s]
        mu_a = float(x_q @ beta_s)
        var_a = float(x_q @ Sigma_s @ x_q)
        if np.any(miss_q):
            var_a += float(np.sum(beta_s[miss_q] ** 2 + np.diag(Sigma_s)[miss_q]))
        z_mod = mu_a / np.sqrt(1.0 + (np.pi / 8.0) * max(var_a, 0.0))
        preds[idx] = 1.0 / (1.0 + np.exp(-np.clip(z_mod, -20.0, 20.0)))

    # Occam's window and BMA softmax
    max_le = np.max(log_evidences)
    keep = log_evidences >= (max_le - 3.0)
    weights = np.zeros_like(log_evidences)
    weights[keep] = np.exp(log_evidences[keep] - max_le)
    weights /= np.sum(weights)
    return float(weights @ preds)
```

### Experiment 2 (Rank 2): Factored Multi-Series BOCPD with Episode Synchrony Gate
- **Target:** Non-stationarity in `shared_change` (0.082) and `drift` (0.070).
- **Estimated Effort:** 2.0 hours | **Runtime:** ~0.5 seconds for 600 machines | **Expected Gain:** +0.4 to +0.7 dev points.

#### Step-by-Step Mathematical & Code Specification
1. **4-Horizon Bank:** Evaluate the per-machine win predictor at 4 exponential forgetting half-lives $h \in \{4, 12, 40, \infty\}$ at every tick $t = 1, \dots, T$. Record each machine's 1-step-ahead predictive log-likelihood:
   $$\ell_{m,t}^{(h)} = \begin{cases} y_{m,t}\log \hat{p}_{m,t}^{(h)} + (1 - y_{m,t})\log(1 - \hat{p}_{m,t}^{(h)}) & \text{if tick } t \text{ is observed on machine } m \\ 0.0 & \text{if tick } t \text{ is missing} \end{cases}$$
2. **Clipped Peer Surprise Aggregation:** Center each machine's log-likelihood relative to the baseline $h = 40$ horizon and clip to $[-1.2, +1.2]$:
   $$\tilde{\ell}_{m,t}^{(h)} = \text{clip}\!\left(\ell_{m,t}^{(h)} - \ell_{m,t}^{(40)},\; -1.2,\; +1.2\right), \qquad S_t^{(h)} = \sum_{m=1}^M \tilde{\ell}_{m,t}^{(h)}$$
3. **Parallel Independent vs. Synchronized Run-Length Recursions:**
   - Define the $4 \times 4$ Markov transition matrix $\mathbf{A}$ over horizons $\{4, 12, 40, \infty\}$ with changepoint hazard $H = 0.025$ (routing mass $H$ from states $\{12, 40, \infty\}$ back to state $h=4$, and advancing $(1-H)$ along $4 \to 12 \to 40 \to \infty$ at rates $1/8, 1/24, 1/80$).
   - Track both $\mathbf{r}_{m,t}^{\text{ind}}$ (with cumulative episode log-evidence $\mathcal{L}_T^{\text{ind}}$) and $\mathbf{r}_t^{\text{sync}}$ (with cumulative episode log-evidence $\mathcal{L}_T^{\text{sync}}$).
   - Combine at cutoff $T$ via $w_{\text{sync}} = \sigma(\mathcal{L}_T^{\text{sync}} - \mathcal{L}_T^{\text{ind}} + \log(1/3))$ and $\mathbf{w}_{m,T} = (1 - w_{\text{sync}})\mathbf{r}_{m,T}^{\text{ind}} + w_{\text{sync}}\mathbf{r}_T^{\text{sync}}$.

```python
import numpy as np

def build_bocpd_transition_matrix(hazard=0.025):
    """4 states corresponding to half-lives [4, 12, 40, inf]."""
    A = np.zeros((4, 4), dtype=np.float64)
    prog = [1.0 / 8.0, 1.0 / 24.0, 1.0 / 80.0]
    for i in range(3):
        A[i, 0] += hazard
        A[i, i] += (1.0 - hazard) * (1.0 - prog[i])
        A[i, i + 1] += (1.0 - hazard) * prog[i]
    A[3, 0] = hazard
    A[3, 3] = 1.0 - hazard
    return A

def run_coupled_episode_bocpd(ll_tensor, hazard=0.025, prior_sync=0.25):
    """
    ll_tensor: shape (M, T, 4) of 1-step-ahead Bernoulli log-likelihoods
               for M machines, T ticks, 4 half-lives [4, 12, 40, inf].
    Returns: horizon_weights of shape (M, 4) at cutoff T, and scalar w_sync.
    """
    M, T, _ = ll_tensor.shape
    A = build_bocpd_transition_matrix(hazard)
    # Center relative to h=40 (index 2) and clip to prevent single-machine outliers
    ll_rel = np.clip(ll_tensor - ll_tensor[:, :, [2]], -1.2, 1.2)

    # 1. Independent per-machine filter
    r_ind = np.tile(np.array([0.10, 0.30, 0.40, 0.20]), (M, 1))
    log_ev_ind = 0.0
    for t in range(T):
        r_prior = r_ind @ A
        lik = np.exp(ll_rel[:, t, :])
        unnorm = r_prior * lik
        norm = np.sum(unnorm, axis=1, keepdims=True)
        log_ev_ind += float(np.sum(np.log(np.maximum(norm, 1e-30))))
        r_ind = unnorm / np.maximum(norm, 1e-30)

    # 2. Synchronized episode-wide filter (Xuan & Murphy 2007 IFM)
    r_sync = np.array([0.10, 0.30, 0.40, 0.20])
    log_ev_sync = 0.0
    for t in range(T):
        r_prior = r_sync @ A
        sum_ll = np.sum(ll_rel[:, t, :], axis=0)
        max_ll = np.max(sum_ll)
        unnorm = r_prior * np.exp(sum_ll - max_ll)
        norm = float(np.sum(unnorm))
        log_ev_sync += np.log(max(norm, 1e-30)) + max_ll
        r_sync = unnorm / max(norm, 1e-30)

    log_prior_odds = np.log(prior_sync / (1.0 - prior_sync))
    w_sync = float(1.0 / (1.0 + np.exp(-np.clip(log_ev_sync - log_ev_ind + log_prior_odds, -20.0, 20.0))))
    weights_M4 = (1.0 - w_sync) * r_ind + w_sync * r_sync[None, :]
    return weights_M4, w_sync
```

### Experiment 3 (Rank 3): Exact 8-Hypothesis Input-Driven Switching Size Filter with Smoothed Gap Triggers
- **Target:** Payout size given win (+1.42 pt oracle ceiling; specifically resolves missing trigger spins in `short_history` and rule shifts in `drift`).
- **Estimated Effort:** 1.5 hours | **Runtime:** ~0.3 seconds for 600 machines | **Expected Gain:** +0.3 to +0.5 dev points.

#### Step-by-Step Mathematical & Code Specification
1. **Extract Type-Level Conditional Size Vectors ($\boldsymbol{\pi}_{\text{type}}^{\text{small}}, \boldsymbol{\pi}_{\text{type}}^{\text{big}} \in \Delta^3$):**
   - For each `machine_type` (`balanced`, `jackpot`, `steady`), extract the two 4-element conditional probability vectors over $\{1, 2, 5, 20\}$ from the validation true probability vectors (and via 2-component Multinomial EM on observed win outcomes in Round 2), softened with a machine-specific Dirichlet prior of concentration $M_0 = 30$.
2. **Smoothed Big-Win Indicator $\hat{b}_\tau \in [0, 1]$ for All Ticks $\tau \in \{1, \dots, T\}$:**
   - Define `is_big_win(y)` as $y \in \{5, 20\}$ (or the empirically verified big-win threshold from train/val).
   - If tick $\tau$ is observed: $\hat{b}_\tau = 1.0$ if `is_big_win(y_tau)` else $0.0$.
   - If tick $\tau$ is missing (in a gap): set $\hat{b}_\tau = \hat{P}_\tau(\text{win}) \cdot \hat{P}_\tau(\text{big win} \mid \text{win})$, updated via Kim's backward smoothing factor from any subsequent observed ticks $\tau + j$ ($j \le 8$) where $\tau$ enters an active parity pair.
3. **Evaluate the 8 Switching Hypotheses $h = (k, d) \in \{1, 2, 3, 4\} \times \{+1, -1\}$:**
   - For each lag $k \in \{1, 2, 3, 4\}$ and polarity $d \in \{+1, -1\}$:
     $$\mathbf{q}_t^{(k, +1)} = \hat{b}_{t-k} \boldsymbol{\pi}_{\text{type}}^{\text{big}} + (1 - \hat{b}_{t-k}) \boldsymbol{\pi}_{\text{type}}^{\text{small}}, \qquad \mathbf{q}_t^{(k, -1)} = \hat{b}_{t-k} \boldsymbol{\pi}_{\text{type}}^{\text{small}} + (1 - \hat{b}_{t-k}) \boldsymbol{\pi}_{\text{type}}^{\text{big}}$$
   - Include a 9th static baseline hypothesis $\mathbf{q}_t^{(0)} = 0.5 \boldsymbol{\pi}_{\text{type}}^{\text{big}} + 0.5 \boldsymbol{\pi}_{\text{type}}^{\text{small}}$.
   - Accumulate discounted log-likelihoods across observed win ticks $y_t \in \{1, 2, 5, 20\}$ at the 4 BOCPD horizons $L \in \{4, 12, 40, \infty\}$, weight hypotheses by their posterior probabilities $w_m(h)$, and multiply $\hat{\mathbf{q}}_{m,T+1}$ by $(1 - \hat{P}_{m,T+1}(0))$.

```python
import numpy as np

WIN_SIZES = {1: 0, 2: 1, 5: 2, 20: 3}

def predict_switching_payout_size(y_hist, b_hat_hist, pi_small, pi_big,
                                  horizon_weights, half_lives=(4.0, 12.0, 40.0, np.inf)):
    """
    y_hist: (T,) array of observed payouts in {0, 1, 2, 5, 20}, or -1 if missing (gap)
    b_hat_hist: (T,) array in [0, 1], exact {0, 1} if observed, smoothed big-win prob if gap
    pi_small, pi_big: (4,) probability vectors over {1, 2, 5, 20} for the machine's type
    horizon_weights: (4,) BOCPD horizon weights from Experiment 2
    Returns: (4,) conditional probability vector P(size | win) at T+1
    """
    T = len(y_hist)
    # 9 hypotheses: 0..3 -> k=1..4 (d=+1), 4..7 -> k=1..4 (d=-1), 8 -> static 50/50
    Q_hist = np.zeros((T, 9, 4), dtype=np.float64)
    q_static = 0.5 * pi_big + 0.5 * pi_small
    Q_hist[:, 8, :] = q_static

    for k_idx, k in enumerate([1, 2, 3, 4]):
        b_lag = np.full(T, 0.25, dtype=np.float64)
        if T > k:
            b_lag[k:] = b_hat_hist[:-k]
        Q_hist[:, k_idx, :] = b_lag[:, None] * pi_big[None, :] + (1.0 - b_lag[:, None]) * pi_small[None, :]
        Q_hist[:, k_idx + 4, :] = b_lag[:, None] * pi_small[None, :] + (1.0 - b_lag[:, None]) * pi_big[None, :]

    # Next-step T+1 candidate emissions under the 9 hypotheses
    Q_next = np.zeros((9, 4), dtype=np.float64)
    Q_next[8, :] = q_static
    for k_idx, k in enumerate([1, 2, 3, 4]):
        b_val = b_hat_hist[T - k] if T >= k else 0.25
        Q_next[k_idx, :] = b_val * pi_big + (1.0 - b_val) * pi_small
        Q_next[k_idx + 4, :] = b_val * pi_small + (1.0 - b_val) * pi_big

    win_ticks = [t for t in range(T) if y_hist[t] in WIN_SIZES]
    if not win_ticks:
        return q_static

    win_ticks_arr = np.array(win_ticks, dtype=np.int64)
    win_cats = np.array([WIN_SIZES[int(y_hist[t])] for t in win_ticks], dtype=np.int64)
    # Log-likelihood of each hypothesis at each winning tick: shape (N_wins, 9)
    ll_wins = np.log(np.clip(Q_hist[win_ticks_arr, :, win_cats], 1e-4, 1.0))

    q_final = np.zeros(4, dtype=np.float64)
    for h_idx, hl in enumerate(half_lives):
        gamma = 1.0 if np.isinf(hl) else (2.0 ** (-1.0 / hl))
        decay = gamma ** ((T - 1) - win_ticks_arr)
        log_post = np.sum(ll_wins * decay[:, None], axis=0)
        # Prior: 0.11 on each of the 8 switching rules, 0.12 on static fallback
        log_post += np.log(np.array([0.11] * 8 + [0.12]))
        w_hyp = np.exp(log_post - np.max(log_post))
        w_hyp /= np.sum(w_hyp)
        q_final += horizon_weights[h_idx] * (w_hyp @ Q_next)

    return q_final / np.sum(q_final)
```
