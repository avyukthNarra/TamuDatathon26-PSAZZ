# Literature sweep for House Edge (g8)

Date: 2026-11-07. Review type: scoping, aimed at methods that can still move the score. Bar: pair mixer v6 at **56.29** (ratios stable .054, short .105, drift .049, shared .056; raw errors .0106 / .0186 / .0093 / .0116). About 60% of v6's squared error is win probability and 40% is payout size. Perfect win probability with v6's sizes would score 58.44 (+2.15). The last ~1.6 points are size. Jackpot live is about half of the win-probability error (truth about 0.58 ± 0.16; v6 RMSE 0.137). Short-history steady is mostly size (about 62% of that cell).

No model was fit in this pass. Gains below are judgments from the mechanism and from the numbers already in `FINDINGS.md` and `g2-pf/REPORT.md`, not new validation scores. Noise between halves is about ±0.4 points. A change under ~0.1 is not worth shipping alone.

Constraint on every idea: stdlib Python, deterministic to 1e-8, constants learned from that round's train and validation targets. Particle filters with a seeded RNG can be made deterministic, but exact dynamic programming is the safer implementation.

## Already tried, so not recommended again

Static Bayes over a fixed rule (about −6 to −12). Fixed-Share (`alpha > 0` in the mixer; it hurt). Logistic or tree models as a replacement, CTW (36.57), PPM (27.60), stacked log-odds (49.44), GRU, and blends with v6. Neighbour, signal, and extra-lag features on the win bit (at most 3.6% of win error). A fixed size atom per machine (53.88, −2.4): the atom switches. Moment-matched Beta level priors (h1: cross-fit 56.32 vs 56.28, inside noise, jackpot slightly worse). A Rao-Blackwellized filter with a per-machine geometric hazard (g2 train-selected: 56.06) and an episode-level abrupt shared run (g2 ablation: 56.30, a tie, and worse on short history). v6 already mixes three half-lives under squared loss, already skips a missing outcome for the count update when the code reaches `value is None`, and already discovers single size lags 1–8. The ideas below are different from those.

One code fact matters for item 4. In `pair_mixer.py`, an expert whose lag cell is missing predicts the machine base rate and still receives a squared-loss weight update. With `decay_missing=True` (the v6 default; `docs/MODEL_PROMPTS.md` states it), every table also decays on missing ticks, so the gap in a short history wipes the 24 older ticks. `discover_size_keys` scores each lag on its own. A pure XOR of two lags has no order-1 correlation, so that search cannot see it.

## Ranked top 10

### 1. Search the size atom as a small non-monotone Boolean function of lagged big-win bits

- Sources: [Maucher, Kracht, Schober, Bossert, and Kestler (2014)](https://doi.org/10.1007/s00180-012-0385-2); the monotone-only negative result in [Maucher et al. (2011)](https://doi.org/10.1093/bioinformatics/btr166); [Liang, Fuhrman, and Somogyi (1998), REVEAL](https://psb.stanford.edu/psb-online/proceedings/psb98/liang.pdf); [Silvescu and Honavar, temporal Boolean networks](http://faculty.ist.psu.edu/vhonavar/Papers/tbn-complex-sys.pdf); [Mossel, O'Donnell, and Servedio (2004), learning juntas](https://www.cs.columbia.edu/~rocco/Public/p049-mossel.pdf); [Blum, Kalai, and Wasserman (2003)](https://arxiv.org/abs/cs/0010022).
- Mechanism: order-1 correlation reconstructs only monotone Boolean rules. XOR/XNOR is flat at order 1 and shows up at Walsh order 2, or as mutual information of the pair jointly (REVEAL). For k=2 and a dozen lags, enumerating pairs beats the subexponential noisy-parity algorithms; those algorithms are for large n.
- Mapping: the size atom. v6's size head and `discover_size_keys` only test one lag. The win rule was a parity and was found by scoring pairs. The same search on a coarsened bit (big win vs not, or the exact class) was never run. Score each candidate by the multinomial likelihood of the next payout given the cell, with the same degrees-of-freedom penalty `discover_size_keys` already uses, dropping rows whose lags are missing. This is also the round-two pair rediscovery if the win pairs move: the hypothesis class has to include order-2 parities or a shifted XOR is invisible.
- Slice: size atom (40% of error, up to about +1.6 if solved) and, through that, short-history steady.
- Round-two safe: yes. The dictionary is structural; the winning lags are whatever this round's train histories support. Atoms, if used as emissions, are re-clustered from that round's targets (`size_modes_from_targets` already does this).
- Cost: low. A few dozen pair cells, pure Python, same shape as `discover_pairs`. An afternoon, no new dependency.
- Expected gain: +0.3 to +1.0 if a k≤2 rule exists, as the win parity did. About 0 if the atom is not a function of lagged payouts. Cheap enough that a null result is informative. This is the highest expected value on the list.

### 2. Two-state filter with known emissions and an explicit duration, as one more size expert

- Sources: [Yu (2010), hidden semi-Markov models](https://www.cs.ubc.ca/~murphyk/Teaching/CS540-Spring10/projects/Yu-hsmm09.pdf) (reviews Ferguson's variable-duration model); [Johnson and Willsky (2013)](https://jmlr.org/papers/volume14/johnson13a/johnson13a.pdf) for the point that geometric sojourns are the wrong default; [Rabiner (1989)](https://doi.org/10.1109/5.18626) for the forward recursion once emissions are known; [Fox, Sudderth, Jordan, and Willsky, sticky HDP-HMM](https://people.eecs.berkeley.edu/~jordan/papers/stickyHDPHMM_LIDS_TR.pdf) only for the self-transition bias. Do not implement the nonparametric sampler. Two states are known.
- Mechanism: with the two categorical atoms fixed, the only latent is the state at each win. A homogeneous HMM forces a geometric run length. An HSMM puts a free distribution on how long an atom stays, truncated at a small maximum (20–40 wins), and the forward pass stays O(T) or O(TD).
- Mapping: the size atom if it persists and then flips without a lag trigger. A fixed atom per machine is already refuted (posterior picks the query atom only about 66%, and plugging it in scores 53.88). A duration model is the next hidden-state hypothesis, and it does not use lags 1/2/4. Add it as another expert in the existing size pool so the squared-loss weights can turn it off.
- Slice: size; secondarily short history, where a short window cannot estimate a lag key but can still sit inside a run.
- Round-two safe: yes. Atom tables come from that round's targets. The duration histogram and the stay probability are counts on train histories.
- Cost: low. Two states, a short duration tail, stdlib lists. Deterministic. Half a day.
- Expected gain: +0.1 to +0.5 if runs are real and the Boolean search in item 1 fails. Near 0 if item 1 already explains the switches. Do not ship it as a replacement for the lag experts; ship it beside them.

### 3. Input-output HMM: the atom is sticky, and the switch can depend on lagged bits

- Sources: [Bengio and Frasconi (1995), NIPS 1994](https://proceedings.neurips.cc/paper_files/paper/1994/file/8065d07da4a77621450aa84fee5656d9-Paper.pdf), journal version [IEEE TNN 1996](https://doi.org/10.1109/72.536317); the static special case is the mixture of experts, [Jacobs, Jordan, Nowlan, and Hinton (1991)](https://doi.org/10.1162/neco.1991.3.1.79).
- Mechanism: two states, emissions fixed to the two atoms. The transition probability is a small function of an input vector (the Boolean features from item 1, or a single big-win bit). Training is EM, or, with two states, a Baum-Welch pass. This is not a generic recurrent net. g3's GRU was a replacement for the whole forecast and scored as useless.
- Mapping: items 1 and 2 are the two pure stories (memoryless function of lags, or a clock with no input). FINDINGS say lags 1/2/4 do not explain the atom and a fixed atom does not either. The leftover is a rule that is mostly persistent and occasionally forced by a lag pattern. An IOHMM is that model. [Shmulevich et al. (2002), probabilistic Boolean networks](https://doi.org/10.1093/bioinformatics/18.2.261) are the wrong noise model: they flip the Boolean function. Here the gate can be deterministic and the payout is a noisy emission.
- Slice: size atom.
- Round-two safe: yes if the input dictionary is the one item 1 selects on this round's train, and emissions are re-read from targets. No main-round lag list.
- Cost: moderate. A 2-state forward-backward with a handful of input bits is a day of stdlib code. Keep the parameter count tiny (a bias plus one weight per selected bit) so 96 episodes can fit it.
- Expected gain: +0.2 to +0.8 if neither pure story holds, else the size-head weights should ignore it. This is the model to try after item 1 comes back partial rather than before.

### 4. Sleeping experts when a lag is missing, and no decay across the gap

- Sources: [Freund, Schapire, Singer, and Warmuth (1997)](https://www.schapire.net/papers/FreundScSiWa97.pdf); regret form in [Kleinberg, Niculescu-Mizil, and Sharma (2010)](https://www.learningtheory.org/colt2008/papers/114-Kleinberg.pdf). The missing-data filter that should replace the base-rate vote is the standard HMM marginalization, as in [Cappé, Moulines, and Rydén (2005), *Inference in Hidden Markov Models*](https://doi.org/10.1007/978-0-387-28982-7).
- Mechanism: a specialist abstains when its inputs are absent. It is left out of the average, and its weight is not touched. v6 does the opposite: a missing cell predicts the base rate, then the squared-loss update is applied to every expert, including the abstaining ones. `decay_missing=True` then multiplies every count by the half-life decay on the gap, which the code comment itself says erases the 24 sampled older ticks.
- Mapping: short history. At the cutoff the last 40 ticks are contiguous, so lags 1–7 are observed and the damage is not the final cell lookup. The damage is learning: sparse older ticks make cells missing, those steps corrupt the weights, and the gap decay throws away the older counts. g2 already skips missing outcomes and averages the two cells for the predictive, and it still lost on short-history win probability (0.00848 vs the mixer's 0.00675). So abstention has to be applied in the mixer, which is the model that wins on short, and on the size head as well as the win head. g4's split says most short/steady error is size, so a win-only fix is capped.
- Slice: short history (.105 vs stable .054).
- Round-two safe: yes. Abstention is structural. There is no new constant. `decay_missing=False` is a flag the class already has; it is not what v6 ships.
- Cost: low. Tens of lines. Do not loss-update an expert whose lag cell is missing. Renormalize the average over experts whose cell is present. If none are present, then use the base rate. Decay only on observed ticks.
- Expected gain: +0.05 to +0.25 on the contest score if the base-rate votes are pulling the short-history weights. Smaller if the recent 40 ticks already dominate the half-life-12 expert. A paired episode comparison on short history is the right test. This is not Fixed-Share, which was tried and hurt.

### 5. One shared flip that keeps the level, plus a ramp, used only as a selector against v6

- Sources: shared location, [Zhang, Siegmund, Ji, and Li (2010)](https://doi.org/10.1093/biomet/asq025) and the convex cousin [Bleakley and Vert (2011)](https://arxiv.org/abs/1106.4199); online filtering, [Adams and MacKay (2007)](https://arxiv.org/abs/0710.3742) and [Fearnhead and Liu (2007)](https://doi.org/10.1111/j.1467-9868.2007.00601.x); a run-length distribution that is not geometric, Fearnhead (2006), [Statistics and Computing](https://doi.org/10.1007/s11222-006-8450-8), and the product-partition prior of [Barry and Hartigan (1992)](https://doi.org/10.1214/aos/1176348521); dependence across the flip, [Fearnhead and Liu (2011)](https://doi.org/10.1007/s11222-009-9163-6); gradual onset and end, preprint [Browne (2022)](https://arxiv.org/abs/2205.01054); choosing among those models online, [Knoblauch and Damoulas (2018)](https://proceedings.mlr.press/v80/knoblauch18a.html). [Wilson, Nassar, and Gold (2010)](https://pmc.ncbi.nlm.nih.gov/articles/PMC2966286/) learn a constant hazard online; less useful here than a train histogram of flip times, because a shared change is one event, not a renewed hazard.
- Mechanism: g2's new run restarts from the prior. On this simulator a shared change flips direction and leaves the pair, the level, and the size atom alone. The segment parameters are dependent: copy the level, swap the cell label. Drift is a ramp, not a step. c1's exact Bayes read every drift episode as a shared flip and scored 53.96. The missing model is an episode-level posterior over three stories whose likelihood is the product of the eight machines: no change, one shared flip at τ, or a linear reversal between an onset and an end. Prefer a grid over τ (T is about 200) to Browne's particle filter, so the result is an exact, deterministic sum.
- Mapping: drift and shared change, and the episode selector in the plan (use a filter where the episode looks stable and long, v6 elsewhere). g2's abrupt shared-run ablation already scored 56.30, better on stable, drift, and shared, worse on short (raw short .0209 vs .0186), and it did not fix jackpot. Repeating that ablation is not a new idea. The new pieces are the level-preserving flip and the ramp, and a hard gate that refuses the filter on short histories.
- Slice: shared change and drift. Indirectly stable, where g2 already beat v6 (.046 vs .054 in the earlier per-machine filter; the episode ablation's stable raw error was .00924 vs .01062).
- Round-two safe: yes if the prior on τ / T and the ramp length are histograms from this round's train, not the main-round "about 0.64 of the cutoff" or "96 down to 34 ticks."
- Cost: moderate. A day for the three-way episode marginal likelihood on top of the existing six rule hypotheses. Stdlib. No particles.
- Expected gain: +0.1 to +0.4 if the selector actually fires only on long stable and clean shared-flip episodes. The abrupt version was a tie (+0.01), so the ramp has to earn the rest. Do not replace v6 outright. [Xuan and Murphy (2007)](https://doi.org/10.1145/1273496.1273629) change the dependency graph at a changepoint; here the pair stays, so that model is the wrong change. [Saatçi, Turner, and Rasmussen (2010)](https://proceedings.mlr.press/v9/saatci10a.html) Gaussian-process changepoints do not fit stdlib or the known discrete rule.

### 6. Logit-normal partial pooling for the win level, predictive mean of p

- Sources: [Aitchison and Shen (1980)](https://doi.org/10.1093/biomet/67.2.261); [Coull and Agresti (2000)](https://www.stat.cmu.edu/~brian/720-2007-source/week07-08-ideas/coull-agresti-2000.pdf); partial pooling worked out for binomial probabilities in the [Stan case study](https://mc-stan.org/learn-stan/case-studies/pool-binary-trials.html) and in Gelman and Hill, *Data Analysis Using Regression and Multilevel/Hierarchical Models* (2007); empirical Bayes, [Robbins (1956)](https://projecteuclid.org/euclid.bsmsp/1200501653) and [Casella (1985)](https://doi.org/10.1080/00031305.1985.10479400). Shrinkage of a vector of means is [Efron and Morris (1975)](https://doi.org/10.1080/01621459.1975.10479864), the Gaussian analogue.
- Mechanism: g1's residual is logit-normal, sd about 0.55 on the logit, around a type×signal centre. A Beta of strength 10 is a different family. The contest loss is squared error on the probability, so the forecast is the posterior mean of p, which is E[logistic(θ)], not the logistic of the posterior mean and not a Beta plug-in at the mean of p. h1 matched Beta moments, got 56.32 vs 56.28, and jackpot got slightly worse. That result caps a prior-centre tweak. It does not test a logit-normal grid (Gauss-Hermite or a fixed logit grid, both stdlib) whose (μ, σ) are fit per type×state.
- Mapping: jackpot live, and short histories, where a single machine has too few live ticks and the eight machines of the episode are exchangeable draws from the same type prior. Pool within type. Do not pool across types. g2 used the same Beta mixture as v6 and also failed to fix jackpot (win-probability squared error about 0.0085 vs 0.00825), so a new prior inside the same mis-specified state model will not do much. The prior only helps after the live/dead state is integrated rather than plugged in.
- Slice: jackpot win level. Secondarily short history.
- Round-two safe: yes. (μ, σ) from this round's targets, cross-fit even/odd episodes if the targets are the validation set used for scoring, or from train-history moments if targets are unavailable.
- Cost: low. A 1-D grid on the logit per type×state. Half a day.
- Expected gain: +0.0 to +0.15. h1 is the reason for the low end. Worth doing inside item 5's filter, not as another standalone prior patch. v6 is already calibrated to about ±0.02 by decile (g4), and the quadratic score is strictly proper ([Gneiting and Raftery (2007)](https://doi.org/10.1198/016214506000001437)), so a post-hoc recalibration of a model whose state is wrong will not fix jackpot.

### 7. Power prior or commensurate prior when round two has a fresh labeled set

- Sources: [Ibrahim and Chen (2000)](https://doi.org/10.1214/ss/1009212673); review [Ibrahim, Chen, Gwon, and Chen (2015)](https://pmc.ncbi.nlm.nih.gov/articles/PMC4626399/); [Hobbs, Carlin, Mandrekar, and Sargent (2011)](https://pmc.ncbi.nlm.nih.gov/articles/PMC3134568/).
- Mechanism: a power prior raises the previous round's likelihood to a0 in [0, 1] and uses that as the prior for the new round. A commensurate prior puts a normal bridge between the old parameter and the new one and lets the data set the precision. If the new train agrees with the old one, a0 stays high. If pairs, atoms, or levels have moved, a0 or the precision collapses and the new data stand alone. a0 = 0 is the "refit from scratch" fallback.
- Mapping: round two, not the main-round validation score. The plan's risk is a 90-minute refit on a shifted kit. Levels, atom tables, the flip-time histogram from item 5, and the size-rule shortlist from item 1 are exactly the parameters these priors were built to carry across studies. [Shimodaira (2000)](https://doi.org/10.1016/s0378-3758(00)00115-4) covariate-shift weights are the wrong tool if the rule itself changes; that is concept shift, which [Gama, Žliobaitė, Bifet, Pechenizkiy, and Bouchachia (2014)](https://doi.org/10.1145/2523813) separate from covariate shift. Domain-adaptation bounds ([Ben-David et al. (2010)](https://doi.org/10.1007/s10994-009-5152-4)) say borrowing hurts once the labeling function moves, which is the commensurate prior's job to detect.
- Slice: all of them, under a shift. Largest insurance value on short history, where the new sample is small.
- Round-two safe: this is the safety device. Fit a0 on the new train only, by marginal likelihood or by prequential Brier. Never freeze a0 from the main round.
- Cost: low for the scalar parameters (levels, hazard histogram, eta). Moderate if the "historical likelihood" is the full mixer likelihood. A one-dimensional line search on a0 is enough.
- Expected gain: about 0 on main-round validation, by construction. On round two, the difference between a stable refit and a noisy one. Not a reason to delay the main-round upload.

### 8. Replace the hardcoded learning rate with AdaHedge, and pick half-lives on this round's train

- Sources: [de Rooij, van Erven, Grünwald, and Koolen (2014)](https://jmlr.org/papers/v15/rooij14a.html); [Koolen and van Erven (2015), Squint](https://arxiv.org/pdf/1502.08009); second-order Hedge, [Cesa-Bianchi, Mansour, and Stoltz (2007)](https://doi.org/10.1007/s10994-006-5001-7). The square loss is mixable, so the aggregating algorithm applies: [Vovk (1998)](https://doi.org/10.1006/jcss.1997.1506); [Haussler, Kivinen, and Warmuth (1998)](https://doi.org/10.1109/18.705569). Prequential choice of a discrete hyperparameter is [Dawid (1984)](https://doi.org/10.2307/2981683).
- Mechanism: AdaHedge sets the learning rate from the cumulative squared loss, with no eta to tune. Squint mixes a prior over learning rates and pays second-order (variance) regret. v6's win eta is 6 or 16 and the size eta is 4, chosen on the main round. `adapt()` rediscovers pairs and size keys and does not retune eta or the half-lives (12, 40, 100). Jackpot's Bernoulli variance is the highest of the three types, which is where a variance-adaptive rate differs from a global eta.
- Mapping: jackpot win level, mildly, and round-two safety of the weight update. The three half-lives should stay as experts. Add a train-only prequential Brier pick of the half-life grid so those numbers are not main-round literals. Do not add Fixed-Share on top: [Adamskiy, Koolen, Chernov, and Vovk (2012)](https://doi.org/10.1007/978-3-642-34106-9_24) show that the usual strongly adaptive construction (interval restarts, [Hazan and Seshadhri (2009)](https://doi.org/10.1145/1553374.1553415)) reduces to Fixed-Share, which already hurt.
- Slice: jackpot, and round two.
- Round-two safe: yes. AdaHedge has no coefficient. The half-life grid is scored on the new train.
- Cost: low. The weight update is a few lines. Squint is a short prior over a log grid of etas.
- Expected gain: +0.0 to +0.1 on the main round. The value is not inheriting eta=6 after the noise level changes. Three half-lives already cover the timescale problem; this is not a second copy of that.

### 9. Mixing Past Posteriors, on the two directions of the current pair only

- Sources: [Bousquet and Warmuth (2002)](https://jmlr.org/papers/v3/bousquet02b.html). The algorithm Fixed-Share is compared with is [Herbster and Warmuth (1998)](https://mwarmuth.bitbucket.io/pubs/J39.pdf), both the fixed and the variable share updates. Variable share still donates weight to every expert. Tracking bounds in general are in [Cesa-Bianchi and Lugosi (2006), *Prediction, Learning, and Games*](https://doi.org/10.1017/CBO9780511546921), chapter on shifting experts.
- Mechanism: after the loss update, mix the current posterior with earlier posteriors, with weight about α/d on the posterior from d steps ago (or the uniform-in-time scheme, which only stores the average and is O(number of experts)). The regret pays log|pool| per switch inside a small pool, not log(number of experts) per switch into the whole set. Drift reverses direction and returns. The pool that reverses is the two directions of one pair, not the other pairs and not the other half-lives.
- Mapping: drift. v6's half-lives already make this the best cell (ratio .049). Fixed-Share hurt because a share step leaks weight onto experts that are simply wrong. MPP with the pool equal to the two directions of the currently leading pair does not. Implement the share inside the pair, across directions, and leave other pairs alone.
- Slice: drift. A small spillover to shared change, which is also a direction flip.
- Round-two safe: yes. Use the paper's 1/d schedule, or fit one α on train prequential Brier. The pool is defined by the pairs discovered this round.
- Cost: low. With a handful of experts, storing the past posteriors for T≈200 is nothing. The O(n) average-of-posteriors scheme is enough.
- Expected gain: +0.0 to +0.1. Drift is already handled. Try it only if items 1–5 are in and there is time. A negative result here should end the tracking-rule experiments: half-lives plus MPP cover the literature, and Fixed-Share is the one that was already rejected.

### 10. Fractional evidence for a missing lag, instead of a base-rate vote

- Sources: the missing-observation forward filter in [Cappé, Moulines, and Rydén (2005)](https://doi.org/10.1007/978-0-387-28982-7); the same recursion is the online changepoint filter of [Fearnhead and Liu (2007)](https://doi.org/10.1111/j.1467-9868.2007.00601.x) once the predictive for a missing context is the model's own mixture of the two cells. g2 already averages the two cells at prediction time and still loses on short win probability, which is why this item is about the update, not the predict step.
- Mechanism: if lag 3 is missing and lag 1 is observed, the parity cell is not "unknown, use the base rate." It is a mixture of the agree cell and the disagree cell, with weights equal to the predictive probability of the missing bit. The count update adds that fraction to both cells. The expert stays awake. Item 4 (abstain, no update) is the safe first cut. Item 10 is the Bayes update when abstention throws away the observed member of the pair.
- Mapping: short history, both heads. The 24 older ticks are the place a lag is missing while the other lag of the pair is often present.
- Slice: short history.
- Round-two safe: yes. No constant.
- Cost: low once item 4 exists. The fractional update is a second branch in the same loop.
- Expected gain: +0.0 to +0.15 on top of item 4, concentrated on short. If item 4 already matches v6, stop. Do not build a general missing-data particle filter; the latent per step is one bit.

## What not to build

- Another Fixed-Share, variable-share, or interval-restart scheme. They are the same family ([Herbster and Warmuth (1998)](https://mwarmuth.bitbucket.io/pubs/J39.pdf); [Adamskiy et al. (2012)](https://doi.org/10.1007/978-3-642-34106-9_24)), and `alpha > 0` already hurt.
- CTW and PPM as win models. [Willems, Shtarkov, and Tjalkens (1995)](https://doi.org/10.1109/18.382012) mix contiguous suffix contexts. The pairs skip a lag, so the context that carries the rule is not a suffix. Matches g3 (CTW 36.57, PPM 27.60).
- A flat Dirichlet-multinomial over {0,1,2,5,20}. The mass factors as a win bit times a two-atom size. A five-way mixture estimates a larger simplex from the same short counts. [Goodman (1974)](https://doi.org/10.1093/biomet/61.2.215) latent class is the right reading of the two atoms: known class-conditional distributions, latent class indicator. The class indicator is items 1–3, not a new mixture family.
- ADWIN-style resets on the drift cell. [Bifet and Gavaldà (2007)](https://doi.org/10.1137/1.9781611972771.42) detect an abrupt mean shift and drop the old window. Drift here is gradual; v6's half-lives are the sliding-weight the [Gama et al. (2014)](https://doi.org/10.1145/2523813) survey recommends for gradual drift. A detector is a candidate only for the shared flip, and item 5 already models that flip with a likelihood.
- Robust BOCPD ([Altamirano, Briol, and Knoblauch (2023)](https://proceedings.mlr.press/v202/altamirano23a.html)). The noise is Bernoulli, not outliers. g4 says v6 is calibrated.
- Recalibration (Platt, isotonic, temperature). The quadratic score is strictly proper ([Gneiting and Raftery (2007)](https://doi.org/10.1198/016214506000001437); the score itself is [Brier (1950)](https://doi.org/10.1175/1520-0493(1950)078%3C0001:VOFEIT%3E2.0.CO;2)). g4's deciles are within ±0.02. A calibrator fit on validation is also a main-round constant.
- Switching linear dynamical systems ([Ghahramani and Hinton (2000)](https://www.gatsby.ucl.ac.uk/publications/papers/11-1999.pdf); [Hamilton (1989)](https://doi.org/10.2307/1912559)) as a win model. The latent is a bit, not a continuous autoregression. The Rao-Blackwell step g2 already did ([Doucet, de Freitas, Murphy, and Russell (2000)](https://www.cs.ubc.ca/~murphyk/papers/rbpf_uai00.pdf)) is the right use of that idea. Another particle filter over continuous levels will not beat a logit grid.
- Large-n noisy parity and junta speedups ([Feldman, Gopalan, Khot, and Ponnuswami (2006)](https://doi.org/10.1109/focs.2006.51); [Blum, Kalai, and Wasserman (2003)](https://arxiv.org/abs/cs/0010022)). At n≤12 and k=2, enumeration is optimal and exact. Cite them only to justify brute force.
- Order-1 correlation as a Boolean-net learner ([Maucher et al. (2011)](https://doi.org/10.1093/bioinformatics/btr166)). Their own guarantee needs monotone functions. XOR is not monotone.

## Annotated bibliography

Grouped by the question it answers. Preprints are marked. Sources below are distinct; arXiv and journal copies of the same paper were collapsed.

### Sparse parity, juntas, lagged Boolean rules

1. Blum, Kalai, and Wasserman (2003). [Noise-tolerant learning, the parity problem, and the statistical query model](https://arxiv.org/abs/cs/0010022). J. ACM 50:506–519. Subexponential noisy parity; at k=2 it says "just check each pattern." Justifies enumeration.
2. Feldman, Gopalan, Khot, and Ponnuswami (2006). [New results for learning noisy parities and halfspaces](https://doi.org/10.1109/focs.2006.51). FOCS. Reduces juntas to noisy parity. Same conclusion at our size: do not implement it.
3. Mossel, O'Donnell, and Servedio (2004). [Learning juntas](https://www.cs.columbia.edu/~rocco/Public/p049-mossel.pdf). STOC 2003 / J. Comput. Syst. Sci. Beats n^k only for large n. For a dozen lags, n^k is the method.
4. Liang, Fuhrman, and Somogyi (1998). [REVEAL](https://psb.stanford.edu/psb-online/proceedings/psb98/liang.pdf). Pacific Symposium on Biocomputing. Mutual information of a candidate input set with the next bit; exact on a complete table, and the right score for a noisy table is the conditional likelihood. Recovers XOR, which margins miss.
5. Silvescu and Honavar (2001). [Temporal Boolean networks](http://faculty.ist.psu.edu/vhonavar/Papers/tbn-complex-sys.pdf). Complex Systems. The next bit may depend on lags 1..T, not only lag 1. Their learner is a decision tree; with k=2 a tree is unnecessary, but the hypothesis class is the right one for both the win pairs and the size atom.
6. Maucher, Kracht, Schober, Bossert, and Kestler (2014). [Inferring Boolean functions via higher-order correlations](https://doi.org/10.1007/s00180-012-0385-2). Computational Statistics. Walsh order 2 sees XOR; order 1 does not. This is the direct critique of `discover_size_keys`.
7. Maucher, Kracher, Kühl, and Kestler (2011). [Inferring Boolean network structure via correlation](https://doi.org/10.1093/bioinformatics/btr166). Bioinformatics 27:1529–1536. Order-1 correlation is consistent for monotone rules only. Negative result for our size search.
8. Akutsu, Miyano, and Kuhara (1999). Identification of genetic networks from a small number of gene expression patterns under the Boolean network model. Pacific Symposium on Biocomputing. Sample complexity of identifying a k-input Boolean rule. At our n, identification is limited by label noise, not by the number of candidates.
9. Shmulevich, Dougherty, Kim, and Zhang (2002). [Probabilistic Boolean networks](https://doi.org/10.1093/bioinformatics/18.2.261). Bioinformatics 18:261–274. A set of functions chosen at random. Wrong noise model for a deterministic gate with a noisy payout. Cited to avoid it.
10. Ribeiro, Magnin, Inoue, and Sakama (2015). [Learning delayed influences of biological systems](https://doi.org/10.3389/fbioe.2014.00081). Frontiers in Bioengineering and Biotechnology 2:81. Learns Boolean rules with explicit delays from observed transitions, which is what a machine history is. Same hypothesis class as Silvescu and Honavar, with a logic-programming learner rather than a decision tree.

### Changepoints: shared, gradual, dependent segments

11. Adams and MacKay (2007). [Bayesian online changepoint detection](https://arxiv.org/abs/0710.3742). Preprint. Run-length filter, constant hazard, independent new segment. This is g2's per-machine filter. The constant hazard and the fresh prior are the two pieces that do not match a single level-preserving flip.
12. Fearnhead and Liu (2007). [On-line inference for multiple changepoint problems](https://doi.org/10.1111/j.1467-9868.2007.00601.x). JRSS-B 69:589–605. Same run-length idea, exact, with an arbitrary segment-length distribution g(·). The general g is how a "flip near a learned fraction of the episode" enters without a hand-set hazard of 0.005.
13. Fearnhead (2006). [Exact and efficient Bayesian inference for multiple changepoint problems](https://doi.org/10.1007/s11222-006-8450-8). Statistics and Computing 16:203–213. Offline exact sampler. Same product-partition structure. T≈200 makes the quadratic recursion free.
14. Barry and Hartigan (1992). Product partition models for change point problems. Annals of Statistics 20:260–279. [DOI 10.1214/aos/1176348521](https://doi.org/10.1214/aos/1176348521). The prior behind BOCPD. A single shared τ is a product partition on the episode, replicated across eight series.
15. Fearnhead and Liu (2011). [Efficient Bayesian analysis of multiple changepoint models with dependence across segments](https://doi.org/10.1007/s11222-009-9163-6). Statistics and Computing 21:217–229. The extension g2 did not run. A flip should copy the level. Independent segments throw the jackpot level away at the one moment it is most expensive to relearn.
16. Zhang, Siegmund, Ji, and Li (2010). [Detecting simultaneous changepoints in multiple sequences](https://doi.org/10.1093/biomet/asq025). Biometrika 97:631–645. Sum of per-series statistics at a common location. The eight machines are the sequences. They allow a subset to share the change; here train says all eight do, and the subset size is a check, not a prior to hard-code.
17. Bleakley and Vert (2011). [The group fused Lasso for multiple change-point detection](https://arxiv.org/abs/1106.4199). Preprint. Convex shared changepoints. A stdlib dynamic program for item 5 is simpler and matches the likelihood; the Lasso is the frequentist twin, not a second implementation.
18. Browne (2022). [A change-dynamic model for the online detection of gradual change](https://arxiv.org/abs/2205.01054). Preprint. Changepoints mark the start and end of a ramp, not the middle of a step. This is the drift model. Use a grid, not the paper's particle filter.
19. Knoblauch and Damoulas (2018). [Spatio-temporal Bayesian on-line changepoint detection with model selection](https://proceedings.mlr.press/v80/knoblauch18a.html). ICML. BOCPD with a posterior over a set of models. The set we want is {stable, one shared flip, ramp}, not their vector autoregressions. The model-selection recursion is the selector.
20. Wilson, Nassar, and Gold (2010). [Bayesian online learning of the hazard rate in change-point problems](https://pmc.ncbi.nlm.nih.gov/articles/PMC2966286/). Neural Computation 22:2452–2476. Learns h, and lets h change. A train histogram of one flip time dominates this for our episodes. Cited so a hierarchical hazard is not rebuilt by accident.
21. Xuan and Murphy (2007). Modeling changing dependency structure in multivariate time series. ICML. [DOI 10.1145/1273496.1273629](https://doi.org/10.1145/1273496.1273629). Changes the graph. Our shared change does not change the pair. Wrong model.
22. Saatçi, Turner, and Rasmussen (2010). Gaussian process change point models. ICML, [PMLR 9:927–934](https://proceedings.mlr.press/v9/saatci10a.html). Right problem (a smooth change), wrong function class for a parity flip, and not stdlib.
23. Altamirano, Briol, and Knoblauch (2023). [Robust and scalable Bayesian online changepoint detection](https://proceedings.mlr.press/v202/altamirano23a.html). ICML. Robustness to outliers. Not our noise.
24. Carlin, Gelfand, and Smith (1992). Hierarchical Bayesian analysis of changepoint problems. JASA 87:673–683. The classical hierarchical single-changepoint model. Item 5 is this, with eight series tied to one τ.
25. Gama, Žliobaitė, Bifet, Pechenizkiy, and Bouchachia (2014). [A survey on concept drift adaptation](https://doi.org/10.1145/2523813). ACM Computing Surveys 46(4). Taxonomy: sudden, gradual, recurring. Shared change is sudden, drift is gradual, direction reversal is recurring. Half-lives match gradual; a detector matches sudden. We already have the gradual tool.
26. Bifet and Gavaldà (2007). [Learning from time-changing data with adaptive windowing](https://doi.org/10.1137/1.9781611972771.42). SDM. ADWIN. Abrupt window drop. Wrong for the ramp; redundant with item 5 for the flip.

### Expert advice under squared loss

27. Herbster and Warmuth (1998). [Tracking the best expert](https://mwarmuth.bitbucket.io/pubs/J39.pdf). Machine Learning 32:151–178. Fixed-Share and Variable-Share. Fixed-Share was tried. Variable-Share still shares onto every expert, so it has the same failure mode on a large junk set of pairs.
28. Bousquet and Warmuth (2002). [Tracking a small set of experts by mixing past posteriors](https://jmlr.org/papers/v3/bousquet02b.html). JMLR 3:363–396. The tracking rule that matches a reversal inside a pool of two directions.
29. Freund, Schapire, Singer, and Warmuth (1997). [Using and combining predictors that specialize](https://www.schapire.net/papers/FreundScSiWa97.pdf). STOC. Sleeping experts. Item 4.
30. Kleinberg, Niculescu-Mizil, and Sharma (2010). [Regret bounds for sleeping experts and bandits](https://doi.org/10.1007/s10994-010-5178-7). Machine Learning 80:245–272. Confirms abstention has a regret bound against the best ordering of the experts that were awake. We are in the full-information case: every awake expert's squared loss is observed.
31. de Rooij, van Erven, Grünwald, and Koolen (2014). [Follow the leader if you can, hedge if you must](https://jmlr.org/papers/v15/rooij14a.html). JMLR 15:1281–1316. AdaHedge. Replaces eta.
32. Koolen and van Erven (2015). [Second-order quantile methods for experts and combinatorial games](https://arxiv.org/pdf/1502.08009). COLT, PMLR 40. Squint. Variance-adaptive. The jackpot cell is the high-variance expert.
33. Cesa-Bianchi, Mansour, and Stoltz (2007). [Improved second-order bounds for prediction with expert advice](https://doi.org/10.1007/s10994-006-5001-7). Machine Learning 66:321–352. The second-order bound AdaHedge refines.
34. Vovk (1998). A game of prediction with expert advice. J. Comput. Syst. Sci. 56:153–173. [DOI 10.1006/jcss.1997.1506](https://doi.org/10.1006/jcss.1997.1506). Aggregating algorithm. Square loss is mixable, so there is a correct substitution function; plain exp(−η(p−y)²) is the gradient version. With a tuned η the gap is small, which is why item 8 is a round-two hedge rather than a score chase.
35. Haussler, Kivinen, and Warmuth (1998). [Sequential prediction of individual sequences under general loss functions](https://doi.org/10.1109/18.705569). IEEE Trans. Inf. Theory 44:1906–1925. The general loss-update v6 is already in. Cited so we do not re-derive Hedge.
36. Hazan and Seshadhri (2009). Efficient learning algorithms for changing environments. ICML. Adaptive regret via interval experts. [DOI 10.1145/1553374.1553415](https://doi.org/10.1145/1553374.1553415).
37. Adamskiy, Koolen, Chernov, and Vovk (2012). [A closer look at adaptive regret](https://doi.org/10.1007/978-3-642-34106-9_24). ALT. Those interval methods are Fixed-Share. This is the reason not to "upgrade" the mixer with an adaptive-regret wrapper.
38. Cesa-Bianchi and Lugosi (2006). *Prediction, Learning, and Games*. Cambridge. [DOI 10.1017/CBO9780511546921](https://doi.org/10.1017/CBO9780511546921). Textbook for the tracking and specialist chapters.
39. Dawid (1984). [Present position and potential developments: statistical theory, the prequential approach](https://doi.org/10.2307/2981683). JRSS-A 147:278–292. How to choose half-lives and a0 on the current train without touching validation.

### Levels, pooling, round-two borrowing

55. Bengio and Frasconi (1995). [An input-output HMM architecture](https://proceedings.neurips.cc/paper_files/paper/1994/file/8065d07da4a77621450aa84fee5656d9-Paper.pdf). NIPS 1994; [IEEE TNN 1996](https://doi.org/10.1109/72.536317). Item 3.

59. Ghahramani and Hinton (2000). [Switching state-space models](https://www.gatsby.ucl.ac.uk/publications/papers/11-1999.pdf). Neural Computation 12:831–864. Discrete regime plus linear dynamics.
