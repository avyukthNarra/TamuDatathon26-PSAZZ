# Round-two member evaluation

Updated: 2026-11-08 17:16 UTC (all candidate evaluations complete)

## Decision rule

A candidate ships only if equal log-odds addition to the current three WIN forecasts improves both fixed-size half scores by **strictly more than +0.100000 points / 40**. The size forecast remains `v13_short` for this primary comparison. Native and fixed-v13-size standalone scores, fixed equal-four additions, and each replacement are reported below to six decimals; `results.json` retains full precision.

## Evaluator and split

Using the supplied `tweak.py` metric: per query, squared error over the five payout classes is averaged within each episode; episode means are averaged within condition; the four condition error/reference-error ratios are averaged. Points = `40 / (1 + mean_ratio)`. The score split sorts the 96 distinct validation episode IDs lexicographically and assigns alternating IDs to A/B (A is index-even, B index-odd), 48 episodes each. This is the requested halves, not a model-fitting split.

The three-member equal log-odds baseline with `v13_short` conditional size is **38.587938 overall; A 38.609258, B 38.593063**. This reproduces the supplied `blend_val.csv` headline of 38.588 when rounded. **Recommendation: retain the current three-member blend; no eligible aligned candidate clears the ship rule.** The all-episodes score need not equal the mean of the two half scores because condition-normalized ratios are recomputed separately on each subset. The kit metadata confirms `max_points: 40`; there are 768 validation queries, 96 episodes, and four conditions.

## Optimized fit-half diagnostics

These `tweak.py` scores fit 10%-step ensemble weights on one evaluator half, then report the opposite-half score. They are descriptive diagnostics from the original candidate files, not clean parity-held-out evidence: original validation-prior folds can include labels from other episodes in the evaluator’s scored half, and v19 also has full-validation gate selection. Do not infer acceptance from these fits. For context, compare the opposite-half scores to the original equal-three baseline (A 38.6093, B 38.5931): v19 fit-A scored B 38.6600 (+0.0669), fit-B scored A 38.4363 (-0.1730); v7c fit-A scored B 38.6460 (+0.0529), fit-B scored A 38.4363 (-0.1730); v17 fit-A scored B 38.6668 (+0.0737), fit-B scored A 38.4363 (-0.1730). The candidate is assigned zero weight in each fit-B winner; these diagnostics do not clear +0.1 on both directions and are not used for the recommendation. Full grid, temperature, size, and drop-one output is in `baseline.log`, `tweak_v7c.log`, and `tweak_v17.log`.
